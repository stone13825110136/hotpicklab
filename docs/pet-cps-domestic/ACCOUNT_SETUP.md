# 联盟账号开户（第 1 天完成）

## 必开（按顺序）

### 1. 京东联盟

1. 打开 https://union.jd.com
2. 用京东账号登录 → 申请成为推广者（个人即可）
3. 实名认证（与收款一致）
4. 创建 **推广位**：
   - 名称示例：`铲屎官严选-主群`
   - 类型：网站 / 社交媒体（选与你实际一致的）
5. 记下 **联盟 ID / 推广位 ID**（后面转链要用）

**收款：** 联盟后台绑定银行卡，按平台周期结算。

---

### 2. 淘宝联盟（阿里妈妈）

1. 打开 https://pub.alimama.com
2. 淘宝/支付宝登录 → 开通淘宝客
3. 完成 **备案媒体**（可填：微信群 / 个人公众号 / 个人网站）
   - 没有网站：选「其他」或「社交平台」，按页面要求填群名/简介
4. 创建 **推广位 PID**：
   - 名称示例：`铲屎官严选主群`
5. 熟悉 **转链**：商品页 → 联盟后台「我要推广」→ 复制链接/口令

**注意：** 部分类目需额外授权；宠物主粮一般可推，以商品页「佣金」显示为准。

---

### 3. 拼多多（第 2 周再开，可选）

1. 拼多多 App 搜索「多多进宝」或打开进宝推广页
2. 开通推广者
3. **仅用于猫砂、玩具、耗材**，主粮暂不推

## 常见问题

**Q：没有网站能开联盟吗？**  
A：可以。媒体类型选社交/社群，按表单如实填。

**Q：链接会过期吗？**  
A：商品下架或活动结束会失效；大促前重新转链。

**Q：退货还算佣金吗？**  
A：不算。确认收货后无退款才结算，退货会扣回。
